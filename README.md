HomeZine – Urban Services App
Overview

HomeZine is an Android application that provides urban services for residents, aiming to simplify city living. The app allows users to:

Access and request municipal services

Track service requests and updates

Explore city-related information and notifications

The project is built using Kotlin and follows the MVVM (Model-View-ViewModel) architecture for a clean, maintainable, and scalable codebase.

Features

Service Requests: Submit, track, and manage municipal service requests

Notifications: Receive updates on request status and city announcements

Dashboard: View personalized summaries of services and tasks

Offline Support: Partial offline support with cached data

Clean Architecture: MVVM with Repository pattern for separation of concerns

Tech Stack

Language: Kotlin

Architecture: MVVM

Android Components: LiveData, ViewModel, Room, Retrofit

Networking: REST API integration using Retrofit

Dependency Injection: Hilt or Dagger (if used)

Data Storage: Room Database for local caching
